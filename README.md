# Abdul Qadir — Portfolio

A single-page developer portfolio (`index.html`, `style.css`, `script.js`, `assets/profile.jpg`).

## Go live for free — GitHub Pages (5 minutes)

1. Go to **github.com** → sign in as `choudharyqadir116-dot`.
2. Click **New repository**.
   - Name it exactly: `choudharyqadir116-dot.github.io`
   - Set it to **Public**
   - Don't add a README (we already have one)
   - Click **Create repository**
3. On the new repo's page, click **"uploading an existing file"** (or drag-and-drop).
4. Upload all 4 items from this folder: `index.html`, `style.css`, `script.js`, and the `assets` folder (with `profile.jpg` inside).
5. Scroll down, click **Commit changes**.
6. Go to **Settings → Pages** in the repo. Under "Build and deployment", Source should already say **Deploy from a branch**, branch **main**, folder **/(root)**. If not, set it and click **Save**.
7. Wait 1–2 minutes, then your site is live at:

   **https://choudharyqadir116-dot.github.io**

That's it — no cost, no expiry, and you can put this exact link on LinkedIn, your CV, and anywhere else.

## Updating it later

Whenever you finish the Medical Store App (or add a new project), just edit `index.html` — each project is one `<article class="receipt">` block — update the text, edit `style: LIVE` status, upload the changed file again, commit. The live site updates automatically within a minute.

## Files

- `index.html` — all content (name, bio, skills, projects, contact)
- `style.css` — all styling
- `script.js` — small scroll-reveal effect + footer year
- `assets/profile.jpg` — your photo
